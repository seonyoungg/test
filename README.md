# 엑셀 날짜 달력 표시기

엑셀/CSV 파일에 입력한 날짜를 읽어 월별 달력에 강조 표시하는 간단한 프로그램입니다.

## 1) 설치

```bash
pip install -r requirements.txt
```

## 2) 실행

```bash
streamlit run app.py
```

## 3) 데이터 파일 형식 (엑셀/CSV)

- 권장 컬럼명: `날짜` 또는 `date` (또는 `일시`)
- 컬럼명이 다르면 첫 번째 컬럼을 날짜로 해석합니다.
- 날짜 예시: `2026-04-15`, `2026/04/15`, `5/1 11:00` (날짜+시간을 한 번에 입력 가능)
- CSV도 지원합니다. (`.csv` 선택 후 업로드)

### 샘플 파일

- `sample_dates.csv` 파일을 업로드해보면 바로 동작을 테스트해볼 수 있습니다.
- 이 파일을 엑셀에서 열고 **다른 이름으로 저장 → Excel 통합 문서(.xlsx)** 로 저장하면 엑셀 파일 예제로도 활용할 수 있습니다.

## 4) 기능

- 엑셀 업로드
- 월 선택
- 해당 월 날짜 강조 표시
- A4 가로형 PNG 다운로드 (안쪽 여백 약 48px)
